# My Memory

Responsive webapp voor notities, checklists en herinneringen, met een headless backend, database, API en MCP.

## Projectstatus

De bouwbrief en alle 20 open bouwstappen zijn op 6 oktober 2026 overgenomen uit het Todoist-project **My Memory**. De repository bevat de plannen en eisen; de app is nog niet gebouwd.

## Documentatie

- [Bouwbrief](docs/BOUWBRIEF.md): volledige projectbeschrijving uit Todoist, inclusief definitieve keuzes en scope.
- [Bouwvolgorde](docs/BOUWVOLGORDE.md): alle 20 bouwstappen met hun volledige beschrijvingen en links naar GitHub-issues.
- [GitHub-issues](https://github.com/pansier/my-memory/issues): open werkzaamheden in de oorspronkelijke bouwvolgorde.

## Werkwijze

Lees de bouwbrief en alle taakbeschrijvingen voordat de bouw begint. Begin bij stap 01 en werk lokaal. Leg voortgang en technische keuzes vast. VPS-hosting is stap 20; een productie-deploy vereist een expliciete opdracht van Alex.

Todoist is bij deze overdracht ongewijzigd gebleven. Deze import is een momentopname, geen automatische synchronisatie.
